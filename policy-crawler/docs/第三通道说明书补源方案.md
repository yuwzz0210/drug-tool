# 第三通道：老药说明书补源方案（步骤3 剩余缺口）

状态：2026-09-06 起草，待选定数据源后执行。

## 1. 缺口量化（去重口径）
- 前两通道合计覆盖 496/1206 品种（drug_leaflet 有 PDF）。
- 唯一药名口径：查无 60 个（两通道收录窗口之外，多为 2019 年前批准的老仿制/老进口/早期生物制品），歧义待人工 14 组。
- 另有 167 个品种在库中无注册文号记录，属于“品种层不完整”，与说明书补源解耦（见品种去重/补全任务）。

## 2. 候选源矩阵
| 源 | 覆盖 | 说明书正文 | 合规/成本 | 结论 |

## 3. 分层执行建议
- L0 自动：NMPA 数据查询回填品种缺失的持有人/厂家/批准日期（提升现有通道匹配与歧义消解）。
- L1 自动：说明书修订公告增量（每日抓标题/文号/链接），命中库内品种则抓附件。
- L2 对接第三方源：选定后写采集/同步器，来源字段记 `source_site`，官方优先。
- L3 人工录入：对 L2 仍缺的高优先品种（按医保目录/目标科室）走现有录入表单 + PDF/OCR。

## 4. 落库与溯源
- 同一品种允许多说明书来源；drug_leaflet.source_url 保留官方或第三方原文链接。
- 新增来源标签字段建议并入现有 extra/文档字典修订后再定。
- 人工录入沿用 is_verified 语义：官方自动=0，人工核验=1。

## 5. 下一步所需决定
1. 是否同意采购/申请第三方源 API（药智或摩熵），预算/账号由你提供；
2. 若不采购：指定“高优先人工补录清单”范围（建议医保目录内 + 库内已关联政策的品种优先）。

## 6. 定位修正（2026-09-06）：不采购第三方库，按官方源“对标自建”
药智/摩熵是**对标对象**（覆盖结构、查询口径、字段组织），不是数据源。
它们的数据绝大多数来自官方公开渠道（NMPA/CDE/医保局/卫健委/各省招采），
本平台改为自建同构库，官方源优先，合法免费。

### 老药说明书缺口（最贵最难部分）的替代打法
2019 前批件官方无集中电子说明书——药智自己的存量也多来自历史公告整理。
方案：NMPA 历史批准/修订公告附件 PDF（OCR）+ 高优先品种人工录入，
不做全量历史回溯，按“医保目录/已关联政策/目标科室”排优先级，逐年增量补齐。

### 落地原则
- 只聚合官方公开数据；采集遵守 robots/频率/UA 合规基线；
- 数据结构以“一药一页”为核心（注册层→说明书层→医保/集采/价格/政策关联层）；
- 覆盖仪表盘量化进度（对标药智可查项逐项打勾），先核心五库：注册、说明书、
  医保、集采、政策。
