# 药品数据分析工具 · 政策呈现优化方案

> 依据参考材料：易联招采网《国家基本药物目录专题》（2026-07-15，49 页 PPT）完整解构。
> 目标用户：平时不太关注政策、但因采购/业务工作需要"大致了解"政策的人。

---

## 第一部分：参考 PPT 的呈现框架解构

### 1.1 整体结构：金字塔式章节 + 一页一主题

```
封面 → 目录（4 大章）→ 每章内部小节编号（1.1 / 2.5.8…）→ 章节过渡页 → 致谢/声明
01 制度发展历程   02 各版目录梳理   03 管理与动态调整   04 配套落地举措
```

- 每章先给"总览页"，再逐项展开（先总后分）；
- 每个具体变化点单独一页，页内只讲一件事（一页一主题）；
- 全文采用教科书式编号（1.2.3 / 2.5.8），让读者知道"我在全文中处于什么位置"。

### 1.2 六个核心呈现手法

| 手法 | PPT 中的体现 | 作用 |
|---|---|---|
| ① 页标题即结论 | "新增中成药覆盖7个领域，独家品种约占80%"、"剔除两个品种" | 不看正文也能抓到重点 |
| ② 时间轴贯穿 | 发展沿革四阶段卡片（S4）；每阶段"时间点→事件"纵向时间轴（S5-S8）；修订历程（S30）；供应保障迭代 2018→2019→2024（S44） | 政策演进脉络一目了然 |
| ③ 对比驱动 | 2015 vs 2026 版逐条对比，**标蓝=变化、标红=新增**（S31-S35）；近三版 520→685→794 大数字对比（S11） | 一眼看到"变在哪里" |
| ④ 数字说话 | 调入 187 / 调出 22 / 净增 165；占比 62.5%；平均间隔 4.5 vs 7.5 年 | 让结论可量化、可信 |
| ⑤ 维度拆解 | 26 版新增 116 个品种，拆成 医保/国采/独家/治疗领域/慢病/肿瘤/中成药/创新药/儿童药/剔除/更名 逐页分析 | 大事件从业务视角切碎理解 |
| ⑥ 结构化要点 | 编号要点 01-06；【变化】【特点】标注；流程图（S37 调整流程）；表格（S43 绩效考核） | 公文语言→可执行要点 |

### 1.3 信息单元的标准模板

每一页几乎都遵循同一信息单元模板：

```
标题（结论句）
├─ 背景/定义（为什么要讲）
├─ 主体内容（时间轴 / 对比表 / 编号要点 / 数据图表）
├─ 【变化】【特点】【结论】标注（增量信息）
└─ 来源标注 + 免责提示（权威背书）
```

### 1.4 可直接迁移到网站的三条经验

1. **结论前置**：把"公文标题"改写成"结论句"，让不熟悉政策的人 3 秒抓住重点；
2. **变化即重点**：用户不需要通读全文，只需要知道"和上次比，变了什么、影响谁、什么时候做"；
3. **同一政策可被多个维度切片**：按 时间线/对比/影响品种 三个维度组织，而不是只按"文件"组织。

## 第二部分：网站政策呈现方案

### 2.1 目标

把政策从"公文堆"变成"一策一页的信息卡"，让采购/业务用户：**看得懂（要点）→ 找得到（关联药品）→ 看得透（对比）→ 追得上（迭代）**。

### 2.2 核心改动：新增「政策详情页」（一策一页）

政策列表点击任意政策进入详情页，按 5 段组织（与品种详情页的"一药一页"同构）：

| 段 | 内容 | 数据来源（现状能力） |
|---|---|---|
| ① 一句话结论 + 核心要点 | 政策"是什么、对谁有影响、要做什么"一句话 + 编号要点 3-6 条 + 关键日期（发布/执行/截止） | `summary` 已有；新增 `key_points` 字段（智能录入可填） |
| ② 影响品种 | 关联药品卡片列表（自动匹配 + 手工关联），每药显示 医保/集采/冷链 状态，点击直达品种详情页 | `relatedPolicies` 反向复用，已有 |
| ③ 历史对比 | 同类型历史政策对比表（时间/来源/核心要求/变化点），标"较上版新增/删除/调整" | 政策库按 type 过滤自动生成，已有数据 |
| ④ 迭代时间线 | 该类政策纵向时间轴（首次→修订→最新），高亮当前政策；可选"发布频次"折线（纯 HTML/SVG，不依赖 ECharts） | `renderPolVTrack` 增强 |
| ⑤ 行动建议 | 采购/业务视角"需要做什么、什么时候做"，叠加截止提醒（剩 N 天/已逾期） | `deadlineTag` 已有 |

### 2.3 政策列表页升级（结论前置）

- 列表卡片标题由"公文全称"改为 **结论式摘要**，如：
  - 原标题：《湖南省关于开展"四同"挂网药品价格治理工作的通知（2026年7月）》
  - 卡片标题：**"湖南四同治理7月批启动：8月5日前完成调价或申投诉，逾期暂停挂网"**
- 保留地区/类型筛选、紧急优先排序、截止标签（已实现）；
- 每条卡片增加「要点」展开（点击展开 ① 的编号要点）。

### 2.4 智能录入增强（支撑要点与结论）

- 解析预览新增字段：`key_points`（核心要点，可自动按"序号句/要求句"粗提取，人工核对）；
- 可选填：`impact`（影响方向：利好/利空/中性）、`conclusion`（一句话结论，留空则按摘要自动生成）；
- 已有 `drug_keywords` 与手工关联保留，作为②段的关联来源。

### 2.5 与品种详情页打通（双向跳转）

- 品种详情页「政策关联」卡片 → 点击政策进入政策详情页；
- 政策详情页「影响品种」→ 点击药品进入品种详情页；
- 形成"品种 ↔ 政策"闭环，符合用户"与对应药品有关联"的核心诉求。

### 2.6 数据模型变更（向后兼容）

政策记录新增可选字段，旧数据不受影响：

```
policy = { ...现有字段, key_points:["要点1","要点2"], impact:"利好|利空|中性", conclusion:"一句话结论" }
```

### 2.7 实施分期

| 阶段 | 内容 | 性质 |
|---|---|---|
| P-A（逻辑） | 政策详情页 5 段视图；要点字段与智能录入；结论式列表卡片；双向跳转 | 功能逻辑 |
| P-B（体验） | 时间轴/对比表视觉美化、大数字、标蓝标红"变化"标注 | UI（并入 UI 轮次） |

### 2.8 验证要点

- 政策详情 5 段完整渲染；要点/结论在无新字段时优雅降级（显示摘要）；
- 同类型历史对比自动生成；迭代时间线高亮当前政策；
- 品种↔政策双向跳转；截止提醒在详情页正常显示；
- 旧政策数据（无新字段）打开不报错。
