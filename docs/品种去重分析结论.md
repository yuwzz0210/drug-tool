# 品种“去重”分析结论（2026-09-06，非破坏性）

## 结论：不建议库层合并删行
精确核查（注册粒度）：
- 同一批准文号挂多个品种：0 条
- 同一 (通用名, 剂型, 规格, 厂家) 完全重复：0 条

同名行多（如 达格列净片 116 行、盐酸二甲双胍缓释片 83 行）是因为库按
“厂家 × 规格 × 文号”逐条注册，属于合法多厂家/多规格数据，不是脏重复。

## 真正需要做的是“呈现层聚合 + 命名规范化”
1. UI/报告按“分子（molecule）”或规范化药名聚合展示，展开显示各厂家/规格
   （一药一页天然支持，避免列表被同名行淹没）。
2. 产品名规范化：全/半角括号、罗马数字、盐基写法统一（normalize 规则已覆盖
   大部分，把规范名回填到展示字段）。
3. 说明书覆盖口径固定为“分子/名称级”，不再按注册行计数（已实现去重报告）。
4. 保留注册粒度数据不动；待“一药一页”UI 落地时按 molecule_id 分组。

不需要执行任何破坏性合并。
