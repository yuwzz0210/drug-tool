# 药品数据分析工具 · P3 政策呈现（一策一页）发布说明

> 按《政策呈现优化方案》实施 P-A 逻辑层：政策从"公文堆"升级为"一策一页"。
> 与品种详情页（一药一页）同构，形成"一药一页 + 一策一页"双亮点。

## 列表卡片呈现逻辑调整（追加）

政策列表卡片改为"标题 → 总结 → 行动 → 建议"的信息流：

```
[政策标题（公文全称）]
[日期 · 地区 · 来源 · 类型 · 影响方向]
总结：<主要内容一句话>
<要采取的行动（有结论字段时显示；旧数据自动结论与建议重复时不再重复显示）>
建议：<建议内容>（去掉 💡 灯泡与底纹框，纯文本）
[截止标签 · 批次 · 关联药品]
[查看原政策原文 ↗]  [删除]
```

卡片上半部分（标题+元信息）仍整块可点击进入「一策一页」，带「查看详情 →」箭头。

## 反馈修正 + P-B（视觉优化）追加说明

### 反馈修正
1. **移除「要点」展开按钮**：政策列表卡片不再需要点击展开要点，信息直接呈现。
2. **整卡上半部分可点击**：结论标题 + 元信息 + 原文副标题整块作为进入「一策一页」的按钮区域，
   带「查看详情 →」箭头和悬停高亮，避免用户不知道点哪里；删除按钮仍在卡片底部独立保留。
3. **逾期标签简化**：逾期超过 3 天只显示「已截止 日期」，不再显示逾期天数；逾期 1-3 天内仍显示
   「逾期 N 天」以便紧急处理。
4. **原政策网址**：政策记录新增 `url` 字段，智能录入可填（无协议自动补 https://），
   政策列表、政策详情页、品种详情政策卡片均显示「查看原政策原文 ↗」外链。

### P-B 视觉优化（政策侧）
- 政策详情页①结论改为**大字号结论块**（22px 加粗 + 蓝色强调条），一眼抓重点；
- 政策迭代时间线加**时间轴竖线与节点圆点**，当前政策高亮；
- 同类政策对比表标注「上一版」（最近一份早于当前的政策高亮），并注明对比基准日期。

## 本次改动

### 1. 新增「政策详情页」（一策一页，5 段）

政策列表点击任意政策标题进入详情页：

| 段 | 内容 |
|---|---|
| ① 结论与要点 | 一句话结论（有 `conclusion` 用原文，无则按 地区+类型+摘要 自动生成）+ 影响方向标签（利好/利空/中性）+ 截止提醒 + 核心要点编号列表 + 原文标题 + 摘要 |
| ② 影响品种 | 关联药品卡片（自动关键词匹配 + `drug_keywords` + 手工关联），每药显示医保/集采状态，点击直达品种详情页 |
| ③ 同类政策历史对比 | 同类型历史政策表（时间/文件/要点），可点击切换查看 |
| ④ 政策迭代时间线 | 该类政策纵向时间轴（首次出台→最新），高亮当前政策，可点击其他节点跳转 |
| ⑤ 行动建议 | 「需要做什么」（建议）+「什么时候做」（截止时间/执行节奏） |

### 2. 政策列表卡片升级（结论前置）

- 卡片标题改为**结论式摘要**，原文标题降级为副标题《…》；
- 无结论字段的旧政策自动生成结论（地区+类型+摘要前 46 字）；
- 新增「要点」展开按钮，点击查看核心要点；
- 影响方向标签（利好/利空/中性）展示在类型旁。

### 3. 智能录入新增字段

- 一句话结论（选填，留空保存时自动生成）；
- 影响方向（利好/利空/中性/未评估）；
- 核心要点（每行一条，选填）。

### 4. 双向跳转闭环

- 品种详情页「政策关联」卡片标题可点击 → 政策详情页；
- 政策详情页「影响品种」→ 品种详情页；
- 实现"品种 ↔ 政策"闭环。

## 数据模型（向后兼容）

政策记录新增可选字段：`conclusion`（一句话结论）、`impact`（利好/利空/中性）、`key_points`（每行一条要点）。旧数据无字段时全部优雅降级，不影响打开与导出。
