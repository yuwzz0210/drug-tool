# 药品数据分析工具 · P2（逻辑项）发布说明

> 按「先确定基本逻辑」的思路，本轮只做 P2 中的功能逻辑项——品种↔政策**手工关联**；
> P2 其余纯 UI 项（标签色板统一、移动端适配、空态/加载态、打印排版）按计划延后到 UI 轮次。

## 第三轮逻辑项：品种对比导出

### 本次改动
- 「品种横向对比」弹窗新增三个动作按钮：**导出 CSV / 复制 / 打印**。
- 导出 CSV：UTF-8（带 BOM，Excel 直接打开不乱码），按对比字段逐行输出，含字段名表头；
  含逗号/引号/换行的单元格自动加引号转义。
- 复制：把同一份 CSV 文本复制到剪贴板（支持旧浏览器降级方案）。
- 打印：对比表按 A4 打印样式输出（弹窗遮罩自动转静态布局）。
- 对比字段抽为共享常量 `COMPARE_FIELDS`，表格与导出共用，保证两者字段一致。

## 第二轮逻辑项：政策截止日期提醒

### 本次改动
- 新增统一的截止日期工具（本地时区解析，避免跨时区差一天）：
  - 已截止：红色「已截止 日期（逾期 N 天）」
  - 当天截止：红色「今天截止 日期」
  - 3 天内：红色「剩 N 天 · 日期」
  - 7 天 / 30 天内：琥珀色「剩 N 天 · 日期」
  - 30 天以上：灰色「截止 日期（剩 N 天）」
- 政策列表新增「☑ 紧急优先」开关：勾选后按 已截止 → 最临近截止 → 无截止 排序；
  列表顶部计数同步显示「已截止 X 条 · 7天内截止 X 条」。
- 品种详情页政策卡片、同省历史批次卡片、政策纵向时间轴统一改用截止提醒标签。

## 本次改动

### 品种详情页「政策关联」支持手工指定
- 详情页「⑥ 政策关联」卡片新增「＋ 手工关联政策」按钮，打开政策选择弹窗：
  - 列出全部政策（可按标题/地区/来源/类型搜索、按类型筛选），勾选后保存即绑定到当前品种；
  - 已关联的政策自动勾选，可随时重新打开调整。
- 关联关系保存在品种记录的 `policy_links` 字段中（随药品库一起导出/备份/恢复）。
- 展示逻辑：自动匹配（标题/摘要/关键词/同地区治理政策）+ 手工关联 **合并去重**展示；
  手工关联的政策卡片带「手工关联」标签和「移除关联」按钮，可单独解除。
- 移除自动匹配的政策仍可用原方式（改关键词或地区），不受影响。

## 部署与验证清单

1. 替换 `index.html` → commit → push，强刷页面。
2. 验证：打开任意品种详情页 → 「⑥ 政策关联」→「＋ 手工关联政策」→ 勾选一条无关政策并保存，
   该政策应出现在详情页并带「手工关联」标签；点击「移除关联」后消失；刷新页面后关联仍然保留。
   再到「政策追踪 → 政策列表」勾选「紧急优先」，确认临期/逾期政策置顶并显示剩余天数。
