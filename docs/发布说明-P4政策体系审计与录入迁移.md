## 本次改动

### 1. 政策智能录入迁移到「数据管理」
- 「政策追踪」导航收敛为 3 个子页：政策列表 / 横向对比 / 纵向追踪（面向业务查看）；
- 「数据管理」新增第 3 个子页「政策录入」（原智能录入完整迁移）：粘贴文本 → 自动识别 →
  补充结论/影响/要点/原政策网址 → 保存入库，保存后自动跳回政策列表查看。
- 录入功能本身零改动（同一套解析与保存逻辑），仅调整归属位置：**查看在政策追踪，维护在数据管理**。

### 2. 政策追踪功能体系审计

#### 功能清单（审计后）
| 功能 | 位置 | 定位 |
|---|---|---|
| 政策列表（结论式卡片 + 紧急优先 + 截止标签） | 政策追踪 | 快速扫一遍 |
| 横向对比（邻省 / 同省批次） | 政策追踪 | 地区维度对比 |
| 纵向追踪（政策迭代时间轴） | 政策追踪 | 类型维度演进 |
| 政策详情页（一策一页 5 段） | 任意卡片点入 | 单政策全貌 |
| 政策录入（智能识别 + 新字段） | 数据管理 | 数据维护 |

#### 重复项判定
- 「纵向追踪」与详情页④「政策迭代时间线」均为同类型时间轴，但视角不同：
  纵向追踪是模块级浏览，详情页④是单政策上下文定位 → **保留，不合并**；
- 列表卡片与详情页①均展示总结/行动/建议 → **分层设计**（列表抓要点，详情展开），非重复；
- 「横向对比」（地区维度）与详情页③「历史对比」（时间维度）互补，非重复。

#### 发现的缺口与本次修复
| 缺口 | 处理 |
|---|---|
| 缺少"同时期政策对比" | 详情页③新增「同期发布（前后 30 天）」区块：同地区优先排序、带同地区标签 |
| 术语不一致（列表"总结：" vs 详情"摘要："） | 统一为「总结：」；"摘要"已全部移除 |
| 全文链接覆盖 | 列表卡片 / 详情页 / 品种详情政策卡片 三处均有「查看原政策原文 ↗」；智能录入可填 url（自动补 https://） |
| 内置示例政策无原文链接 | 属数据问题，需人工在录入/编辑时补充 url（审计结论：功能已就绪） |

#### 保持原样并说明
- 「横向小结」「批次趋势」标题风格不同但语义不同（横向 vs 纵向趋势），保留；
- 逾期/截止标签、紧急优先排序已统一复用同一套工具函数。
