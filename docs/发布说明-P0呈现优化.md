# 药品数据分析工具 · P0 呈现优化发布说明

> **更新提示**：P1 模块整合版（见《发布说明-P1模块整合.md》）已上线，主导航收敛为 4 项、
> 数据管理拆分为「数据维护/工具区」，并新增政策↔品种关联。P0 的详情聚合页与搜索能力全部保留。

> 本版本在「稳定性优化版」基础上叠加 P0 呈现优化（搜索优先 · 一药一页）。
> 部署后整体替换仓库根目录 `index.html` 即可。

## 本次改动

### 1. 全局搜索升级（搜索优先）
- 顶部搜索支持通用名 / 商品名 / 拼音（首字母与全拼）模糊匹配，按「精确 > 前缀 > 包含 > 拼音」排序。
- 搜索结果卡片直接显示：准入评分等级（A/B/C/D）、医保状态、双通道、冷链等标签。
- 支持回车直达第一个结果、ESC 关闭下拉。
- 选中药品后不再跳「临床简报」，而是进入**品种详情聚合页**。

### 2. 新增「品种详情聚合页」（一药一页）
搜索、引进评估列表、竞争格局对比表均可点击药品名进入，页面按医药行业决策链组织 7 段：

| 段 | 内容 |
|---|---|
| ① 概览 | 评分等级 + 推荐标签 + 医院青睐度 + 医保/集采/双通道/冷链/专利标签 + 一句话结论 |
| ② 基本信息 | 批准文号、剂型规格、厂家、机制、适应症、专利等（复用原详情字段） |
| ③ 市场与价格 | 挂网价、年化费用、采购价、价格历史时间线 |
| ④ 准入路径 | 六维评分明细条 + 权重说明 + 「调整权重」入口 |
| ⑤ 竞争格局 | 代际演进时间轴（当前品种高亮）+ 替代窗口提示 + 同病种横向对比表（可勾选对比） |
| ⑥ 政策关联 | 与品种相关的政策卡片（关键词/地区自动匹配）+ 截止日期提醒 |
| ⑦ 一键输出 | 生成临床简报 / 品种分析简报（页内生成，支持打印与复制） |

### 3. 移除低价值柱状图，ECharts 整体下线
- 竞争格局「迭代时间线」由 ECharts 柱状/折线图改为 **HTML 代际时间轴**（纯文本时间线，信息密度更高）。
- 移除后全站不再引用 ECharts，**第三方 CDN 依赖仅剩 pinyin-pro 一个**（且带多源回退、失败自动降级）。
- 上一轮为 ECharts 做的「加载失败降级提示」随之失去意义，相关代码已一并移除。

### 4. 对比表格适配多场景
- `competeTable` 支持自定义容器，详情页内的「对比所选品种」与竞争格局模块各自独立工作。
- 所有对比表、评估表中的药品名改为可点击链接，统一进入详情聚合页。
